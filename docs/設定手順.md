# おうちボード 設定手順

全部で15分くらい。パソコンで ①〜③、iPad で ④〜⑥ を行います。

## ① 裏方（Google Apps Script）を作る（パソコン）
1. https://script.google.com を開き、「新しいプロジェクト」を押す。
2. 左上の「無題のプロジェクト」を「おうちボード」に変える。
3. エディタに最初から入っている `function myFunction() {}` を全部消し、`gas/Code.gs` の中身を全部貼り付けて保存（Ctrl+S）。

## ② 初回設定を実行する
1. 上のメニューで関数 **setup** を選び、「実行」を押す。
2. 「承認が必要です」→ 自分のアカウントを選ぶ。
   「このアプリは Google で確認されていません」と出たら「詳細」→「おうちボード（安全ではないページ）に移動」→「許可」。
   （自分で書いたスクリプトを自分で使うときに必ず出る表示です。カレンダー・スプレッドシート・外部通信の許可を求めます。）
3. 下の「実行ログ」に次の2つが出る。
   - **合言葉（key）**：あとで iPad に入れる
   - **データのスプレッドシート**：ルーティンの追加・変更はここで行う

## ③ ウェブアプリとして公開する
1. 右上の「デプロイ」→「新しいデプロイ」。
2. 歯車 →「ウェブアプリ」を選ぶ。
3. 「次のユーザーとして実行」：**自分**、「アクセスできるユーザー」：**全員**。
   （合言葉がないと何も返さないので、URL を知られても中身は見られません。）
4. 「デプロイ」を押し、出てきた **ウェブアプリの URL（…/exec で終わる）** をコピーする。

## ④ iPad で開いて設定する
1. iPad の Safari で https://okiba8a-stack.github.io/ouchi-board/ を開く。
2. 「ウェブアプリのURL」と「合言葉」を入れて「保存してつなぐ」。
3. 「つながりました」と出たら、**そのまま** 共有ボタン →「ホーム画面に追加」。
   （アドレスに設定が入った状態で追加するので、ホーム画面のアプリにも設定が引き継がれます。）
4. ホーム画面の「おうちボード」から開くと、Safari の枠なしの全画面で表示されます。
5. 上端の表示はアイコンを追加したときの設定で決まります。2026-11-15 14時より前に追加したアイコンは、上が黒い帯になるか、上がぼやけます。
   ツールの画面 →「接続と更新」→「ホーム画面に入れ直す」でアドレスをコピーし、Safari に貼り付けて開き、共有 →「ホーム画面に追加」。
   新しいアイコンでは、時刻・電池の表示の部分が写真の上端の色の帯になり、ぼかしはなくなります。天気は右上に出ます。
   新しいアイコンで直ったのを確かめてから、古いアイコンを消してください。

## ⑤ 壁掛け用の iPad の設定
- 設定 →「画面表示と明るさ」→「自動ロック」→ **なし**（画面を消さない）。
- 設定 →「アクセシビリティ」→「アクセスガイド」をオン。おうちボードを開いた状態でトップボタン（ホームボタン）を3回押すと、おうちボードから出られなくなります。解除も3回押し。
- 夜23時〜朝6時は画面が自動で暗くなり、時計だけが見えるようになります。

## ⑥ 「リマインダー」の通知を受け取る
- リマインダーは専用の Google カレンダー「リマインダー」に入り（setup で自動で作られる）、その時刻に通知が出ます。
- iPhone で Google カレンダーアプリの通知をオンにし、「リマインダー」カレンダーが表示（同期）されていることを確かめる。

## そのあと
- ルーティンの追加・変更：ツールの画面の「ルーティンの編集」か、スプレッドシート「おうちボード データ」の routines シート（曜日は空欄か「毎日」、または「月水金」）。
- 裏方のプログラムを更新したとき：「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」。URL と合言葉は変わらない。
- 合言葉を変えたいとき：関数 **resetKey** を実行し、ツールの画面の「接続と更新」→「接続の設定」から入れ直す。
- 画面のプログラムは GitHub（okiba8a-stack/ouchi-board）にあり、更新すると5分以内に iPad でも自動で新しくなる。
- **2026-11-15 の裏方の更新（任意）**：gas/Code.gs を貼り直して新バージョンをデプロイすると、次が使えるようになる。貼り直さなくても、ほかの機能はそのまま動く。
  - 月のカレンダーに予定が出る（貼り直す前は祝日とごみの日だけ）
  - ルーティンの「○回連続」
  - 天気の配信が止まったときに、裏方が前回の天気を返す
  - 引っ越したときに、スクリプト プロパティで地点を変えられる（下の「引っ越したとき」）

## Gmail と Google ToDo の連携（2026-11-15 追加）
1. gas/Code.gs を Apps Script に貼り直して保存する。
2. （Google ToDo を使うとき）エディタの左の「サービス」の ＋ →「Tasks API」→「追加」。
3. 関数 **setup** を実行し、Gmail（と Tasks）の許可を求められたら許可する。
4. 「デプロイを管理」→ 鉛筆 →「新バージョン」でデプロイする。
- **Gmail**：大事な未読メール（受信トレイ・未読・重要マーク・3日以内）があると、時計の画面に「メール　大事な未読 2件」と出る（件名は壁に出さない）。件名は「きょうのまとめ」と、アシスタントに「メールは？」と聞いたときに答える。大事の条件はスクリプト プロパティ `MAIL_QUERY` で変えられる（例：`in:inbox is:unread (is:important OR from:ac.jp)`）。
- **Google ToDo**：メモ・買い物の保存先が Google ToDo のリスト「おうちボード」になる。iPhone の Google ToDo アプリ（または Gmail・カレンダーの横の ToDo）で、外出先でも買い物リストを見て、チェックできる。それまでのメモは最初の一回だけ移る。元のスプレッドシートに戻したいときは、スクリプト プロパティ `MEMO_TASKS` を `off` にする。

## 写真を表示する
1枚目の画面に、Google ドライブの写真を全面表示できる。

1. Apps Script で関数 **setup** を実行する（ドライブの許可を求められたら許可）。マイドライブに「おうちボード 写真」フォルダができる。
2. そのフォルダに写真を入れる（iPhone なら Google ドライブのアプリから）。ツールの「壁紙と写真」→「写真を選ぶ」でも入れられる（縮小して入る）。
   - 横長の写真がきれいに収まる。5分ごとに次の写真に変わり、表示中はゆっくり寄る。
   - 一度出た写真は端末に保存され、次からは通信なしですぐ出る。
   - 「壁紙と写真」の一覧で ◀ ▶ で順番を変え、× を2回押すと削除（ドライブのゴミ箱に入り30日は戻せる）。
3. 壁紙は次から選べる（端末ごとに覚える）。
   - 自分の写真／山なみ／きょうの絶景（Bing の日替わり写真。個人で見る用途に限る）
   - **写真のグループ**（裏方は使わない）：世界遺産（約3,200か所）・日本の名所（約770）・世界の自然（約450）・城と宮殿（約230）・世界の名画（約800）は、ウィキデータの一覧から。風景の名作・宇宙・生きもの・植物は、ウィキメディア・コモンズの「秀逸な写真」から毎回ランダムに。「おまかせ」は全部をまぜる。
   - グループの写真のときは、時計の画面の右下に小さく「名前 ・ 国名（日本の名所は都道府県名）　くわしく ›」と出る。押すと、日本語版ウィキペディアの解説・地図・写真の出どころ（撮影者とライセンス）が出る。コモンズの写真（宇宙など）の説明は英語のことが多い。
   - 一覧は最初の1回だけ読み込みに数十秒かかり、そのあと30日は端末に覚える。

## 画面の使い方

### 全体
- 横にスワイプすると、時計 → 予定とルーティン → ツール → ニュース の順に切り替わる。輪につながっていて、時計の左がニュース。下の点をタップしても移れる。3分さわらないと時計の画面に戻る。
- 時計・電池の表示の部分は、写真の上端の色に合わせた帯になる（写真を裏まで出すと iOS 26 以降は上端が必ずぼかされるため、ぼかしのない帯を選んだ。2026-11-15）。上がぼやけるアイコンは古い設定 → 「接続と更新」→「ホーム画面に入れ直す」。
- 夜（23〜6時）は画面全体を暗くし、写真もほぼ消して時計だけが見える。
- どこかで震度5弱以上、または地点の都道府県で震度2以上の地震があると、どの画面にも上に帯が出る（15分間。× で消せる。P2P地震情報。緊急地震速報の代わりにはならない）。
- Wi-Fi が切れていても、前回の画面と最後に読んだ情報を出す。つながり直すとすぐ読み直す。2時間以上読めないと、時計の画面に「更新できていません」と出る。

### 時計の画面
- 右上：いまの気温（体感温度と2度以上違えば「体感 11°」）、きょう・あしたの天気。天気を押すとくわしい天気（24時間の天気・紫外線・日の出と日の入り・雨雲レーダー）。
- 日付の横に祝日の名前。時計を押すとアラーム。予定の行を押すと予定の画面。それ以外を押すと次の写真。
- 下の行に、次のものが札つきで出る：
  - いま／つぎの予定（2時間以内なら「あと25分」、いまの予定は終わる時刻）
  - きょうの終日の予定、リマインダー
  - 気象警報・注意報（地点の市区町村。警報以上は赤。気象庁のデータを10分おき）
  - ごみ（当日は12時まで）／あしたのごみ（前の晩18時から）
  - あと○日（7日以内のカウントダウン）、そろそろ（期限を過ぎたときどきやること）
- その下に雨のひとこと（「15時ごろから雨の予報。洗濯物は14時までに取りこんで。」など。毎時の降水確率50%以上を雨として決まった文で作る）と、裏方の天気のひとこと。

### 予定とルーティンの画面
- **きょうの予定・この先一週間**：行を長押しすると編集・削除（削除は2回押し）。くり返しの予定と他人のカレンダーは変えられない。「月のカレンダー」で1か月分（祝日は赤、ごみの日は黄色、予定は緑）。
- **予定を追加**：「あさって15時 歯医者」のように書くと Google カレンダーに入る（時刻がなければ終日）。
- **きょうのルーティン**：押してチェック。続けると「7回連続」（曜日を決めたものはその曜日だけ数える）。
- **ときどきやること**：「シーツ交換 14日ごと」「歯ブラシ 1か月」と書いて追加。前回から何日かが出て、やったら「やった」。決めた日数を過ぎると「そろそろ」。「消す」は2回押し。
- **リマインダー**：「1週間後にラップを外す」のように書くと、専用の Google カレンダー「リマインダー」に通知つきで入る（iPhone の Google カレンダーアプリで通知）。右の丸で済みにする。
- **カウントダウン**：「旅行 12/20」と書くと「あと35日」。過ぎたら自動で消える。
- **メール**（右の列の上）：受信トレイの未読の件数、大事な未読（黄色の「大事」）、メインのタブの新しい未読を出す。「開く」でそのメールを Gmail で開き、「既読」で既読にする。「Gmail を開く」で受信トレイ、「受信トレイを全部既読」（2回押し）ですべて既読。裏方の更新（2026-11-15 夜の版）が要る。
- **けさのまとめ**（メールの欄の上の黄色い枠）：毎朝 7:05 に Claude（claude.ai のルーチン「毎朝のGmail確認」）がきのうからのメールを読み、大事なものをまとめてドライブのフォルダ「おうちボード けさのメール」にテキストで置く。ボードはいちばん新しいものを24時間出す。古いファイルは7日で自動でゴミ箱へ。カレンダーには、日時がはっきりした締切・予約だけ入る。

### ツールの画面（小さなカード。右上の矢印で大きく開く）
- **アシスタント**：「タイマー10分 パスタ」「あしたの予定は？」「牛乳をメモ」など。ボタンで「きょうのまとめ」（天気・雨・警報・予定・ごみ・そろそろ・カウントダウンをまとめて答える）、「ごみの日」なども聞ける。「シーツ交換はいつやった？」「旅行まであと何日？」にも答える。「声で返事する」で読み上げ。
- **タイマー・アラーム**：アラームはおうちボードを開いている間だけ鳴る（iPad の音量を上げておく）。
  - アラームの窓の「曲を選ぶ」で、「ファイル」アプリの mp3・m4a などを音にできる（iPad の中に保存。小さな音から1分かけて大きくなる。最長5分）。Apple Music の曲はコピー防止のため使えない。iPad の時計アプリのアラームはアクセスガイド中に鳴らないことがあるが、おうちボードのアラームは鳴る。
  - Apple Music の曲で起きたいときは、ショートカットのオートメーションも試せる：ショートカット →「オートメーション」→ ＋ →「時刻」→ 時刻と「すぐに実行」→ アクション「ミュージックを再生」でプレイリストを選ぶ。アクセスガイド中に動くかは未確認なので、最初はおうちボードのアラームと併用する。
- **メモ・買い物**：2回以上入れたものは「＋牛乳」のボタンで出る（いつもの買い物）。
- **週間天気**：7日分と日の出・日の入り。
- **壁紙と写真**：上の「写真を表示する」。
- **ごみの日**：1行に1つ「燃えるごみ 月 木 8:30まで」「資源ごみ 第2・第4 金」「古紙 11/5 11/19」「休み 12/30-1/3」のように書いて保存。1週間分が出る。
- **ルーティンの編集**：名前・曜日の変更、追加、削除。「保存」で反映。
- **表示の設定**（「接続と更新」のカードの中）：夜に暗くする時間帯（暗くしない、も選べる）、写真の切り替えの間隔（1分・5分・15分・1時間）、時計の下の行に出すもの、大事なメールの条件（Gmail の重要マーク、大事にする差出人、さかのぼる日数。これだけ裏方に保存）。
- **接続と更新**：版の表示、最新版に更新、接続の設定、ホーム画面に入れ直す、来客用 Wi-Fi の QR（ネットワーク名とパスワードを入れて「QR を出す」。お客さんが iPhone のカメラで読むとつながる。パスワードはこの端末にだけ保存）。

### 端末に保存されるもの
ごみの日・ときどきやること・カウントダウン・Wi-Fi・壁紙の選択は、この iPad の中に保存される（Wi-Fi 以外は「ホーム画面に入れ直す」のアドレスにも入るので、入れ直しても消えない）。

## iPad でフリック入力を使う
1. 設定 →「一般」→「キーボード」→「キーボード」→「新しいキーボードを追加」→「日本語」→「かな入力」を追加する。
2. 文字を打つ画面でキーボードを2本指でつまむ（ピンチイン）と、小さいキーボードになり、フリック入力ができる。キーボード右下のマークを長押し →「フローティング」でも同じ。
3. 元に戻すときは、小さいキーボードを2本指で広げる。

## 引っ越したとき（地点を変える）
1. （一度だけ）gas/Code.gs を Apps Script に貼り直し、新バージョンでデプロイする。
2. Apps Script の「プロジェクトの設定（歯車）→ スクリプト プロパティ」に、次の3つを追加する。
   - `PLACE`：都道府県から市区町村まで（例：`東京都世田谷区`、`神奈川県横浜市港北区`）
   - `LAT`・`LON`：緯度・経度（Google マップで家を長押しすると出る数字。例：`35.6464`、`139.6532`）
3. 30分以内に、天気・雨雲レーダー・日の出と日の入り・紫外線・体感・気象警報・地震の帯の判定がすべて新しい地点に切り替わる（警報の区域は PLACE の地名から自動で引く）。
4. ごみの日を書き直す（ごみカレンダーの写真を Claude に送れば、規則の文を作ってもらえる）。
