# おうちボード Webアプリ化 開発計画

目的：claude.ai のアーティファクト版おうちボードを、iPad のホーム画面から全画面で開ける自分用 Web アプリにする。費用ゼロ。

## 構成
- 画面：`index.html` ほか（GitHub Pages、リポジトリ okiba8a-stack/ouchi-board、公開）
- 裏方：`gas/Code.gs`（Google Apps Script のウェブアプリ。本人のアカウントで動く）
  - Googleカレンダー：今日〜8日分を読む／「覚えておいて」で通知つき予定を作る
  - 天気：Open-Meteo（日野市、30分キャッシュ）
  - ニュース：Google ニュース RSS（60分キャッシュ、個人利用）
  - ルーティンとチェック：スプレッドシート「おうちボード データ」
- 合言葉（key）は GAS のスクリプトプロパティにだけ置き、リポジトリには入れない。
