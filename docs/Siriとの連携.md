# Siri・Claude との連携

おうちボードの「アシスタント」は、iPhone / iPad の Siri からも呼べます。
裏方（Apps Script）を最新にしてから設定してください。

## 1. 「ボードに頼む」ショートカットを作る（5分）

iPhone の「ショートカット」アプリで、右上の「＋」から新しく作ります。

1. アクション「**テキストを音声入力**」を追加する。言語は「日本語」にする。
2. アクション「**URL**」を追加し、次を入れる（`合言葉` は自分の合言葉に置きかえる）。

   ```
   https://script.google.com/macros/s/（ウェブアプリのID）/exec?action=say&key=合言葉&text=
   ```

   `text=` のすぐ後ろをタップして、変数「**音声入力されたテキスト**」を入れる。
3. アクション「**URLの内容を取得**」を追加する（方法は GET のまま）。
4. アクション「**辞書の値を取得**」を追加し、キーに `reply` と入れる。
5. アクション「**テキストを読み上げる**」を追加する。
6. 上の名前を「**ボードに頼む**」にして完了。

使い方：「Hey Siri、ボードに頼む」→ 話す。

| 言い方の例 | 起きること |
|---|---|
| 1週間後にパンチェッタのラップを外す | リマインダーに登録（その時刻に通知） |
| 明日の15時に歯医者の予定 | カレンダーに予定を追加 |
| 牛乳を買うってメモして | メモ・買い物に追加 |
| 今日の予定は？／明日の天気は？ | Siri が読み上げて答える |

- 日時がある文はリマインダー、「予定」と言えばカレンダー、どちらでもなければメモになります。
- タイマーは「Hey Siri、10分タイマー」のほうが確実です（Siri のタイマーは iPad を閉じていても鳴ります）。
- ウェブアプリのURLと合言葉は、おうちボードの設定の画面 →「接続の設定」で確認できます。

### もっと賢くしたいとき：間に Claude をはさむ（Claude のアプリが入っていれば無料）
手順 1 と 2 の間に、Claude アプリのアクション「**Ask Claude**」を入れ、メッセージを次のようにします。

```
次の文を、日時をはっきり書いた短い一文に直してください。答えは直した文だけ。
今日は（「現在の日付」の変数）です。
文：（「音声入力されたテキスト」の変数）
```

手順 2 の `text=` には、音声入力の代わりに **Ask Claude の結果** を入れます。
「来週のどこかで歯医者」「再来週の水曜の夕方」のような言い方も、はっきりした日時になって届きます。

## 2. ボードのアシスタントを Claude にする（任意・有料）

アシスタントは、ふだんは決まった言い回しで判断します（無料）。Claude の API キーを入れると、自由な言い方が通じ、
「今日は傘いる？」「明日の午前は空いてる？」のような質問にも答えます。

1. https://console.anthropic.com で API キーを作る（使った分だけ料金がかかります）。
2. Apps Script の左の歯車「プロジェクトの設定」→ 一番下「スクリプト プロパティ」→「プロパティを追加」。
   プロパティ `ANTHROPIC_API_KEY`、値に API キーを入れて保存する。
3. おうちボードを開き直すと、アシスタントの見出しの横に「Claude が読み取ります」と出る。

- 使うモデルは `gas/Code.gs` の先頭の `CLAUDE_MODEL`（はじめは `claude-opus-5-5`）。安くしたいときは `claude-haiku-5-5` に変えられます。
- API キーはスクリプト プロパティにだけ置きます。画面や GitHub には出ません。
- Claude がうまく答えられなかったときは、自動で決まった言い回しの判断に戻ります。

## 3. ボードの中での使い方
- 「ツール」の画面の「アシスタント」に書くか、🎤 を押して話す（🎤 は使える端末でだけ出ます）。
- 「声で返事する」にチェックを入れると、返事を読み上げます。
- タイマーは 3・5・10・15・30分のボタン、または「タイマー10分 パスタ」。時計の画面にも残り時間が出ます。
