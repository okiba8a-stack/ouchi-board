# おうちボード

iPad を壁掛けにして使う、自分用の家のボード。ホーム画面に追加して全画面で使う。

## 画面（横にスワイプ、輪になっている）
- **時計**：壁紙の写真（ゆっくり寄る）、いまの気温・体感、きょう・あしたの天気、祝日、つぎの予定と残り時間、ごみの日、気象警報、カウントダウン、「そろそろ」やること、雨の降り出し・止む時刻。夜は時計だけ。
- **予定とルーティン**：きょうの予定・この先一週間・月のカレンダー、ルーティンのチェックと連続記録、ときどきやること（前回から何日）、リマインダー、これからの天気、カウントダウン。
- **ツール**（小さなカード、右上の矢印で拡大）：アシスタント（きょうのまとめ等）、タイマー・アラーム、メモ・買い物（いつもの買い物の候補）、週間天気（日の出・日の入り）、壁紙と写真、ごみの日、ルーティンの編集、接続と更新（来客用 Wi-Fi の QR）。
- **ニュース**
- どの画面にも：地震の帯（P2P地震情報）。

## 作り
- 画面：`index.html`（GitHub Pages）。部品は `remind-parse.js`（日時の読み取り）・`gomi.js`（ごみの日の規則）・`sun.js`（日の出・日の入り）。`sw.js` はつながらないときに前回の画面を出す。
- 裏方：`gas/Code.gs`（Google Apps Script、本人のアカウントで動く）。地点はスクリプトプロパティ PLACE・LAT・LON。
- 画面から直接読む公開データ：Open-Meteo（紫外線・体感）、気象庁（警報）、RainViewer・地理院タイル（雨雲レーダー）、holidays-jp（祝日）、P2P地震情報。
- 設定の仕方：[docs/設定手順.md](docs/設定手順.md)　計画：[docs/開発計画.md](docs/開発計画.md)

## 確かめ方
- 試し表示：`index.html?demo=1`（`&page=1`〜`3`、`&tool=gomi`、`&sheet=wx`・`cal`、`&warn=1`、`&quake=1`、`&soon=1`、`&sa=24` で上端の余白を真似る）
- テスト：`node test/remind-parse.test.js`、`node test/gomi.test.js`、`node test/sun.test.js`
- 公開：`python release.py` で版をそろえてから commit・push（開いたままのボードは5分以内に自動で読み込み直す）
